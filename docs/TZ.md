# ТЗ — Сайт кав'ярні Smart Bar

> **Версія:** 0.2 · **Дата:** 2026-08-24 · **Статус:** узгоджено ключові рішення, розпочинаємо розробку
> **Платформа:** веб-сайт (Next.js 14, App Router) · **Мова:** українська · **Ціль:** онлайн-продаж кави, чаю

---

## 1. Мета та бізнес-цілі

Створити **сучасний, візуально привабливий сайт-вітрину** для кав'ярні Smart Bar з функцією онлайн-замовлення. Основна мета — **продавати асортимент**: кава зернова/мелена, чай, кава на розваг. Доставка — Новою поштою по всій Україні.

**Референс дизайну:** https://cafemino.com.ua/ (прямий конкурент). Треба взяти стилістику, UX-патерни, але не копіювати контент/бренд.

---

## 2. Цільова аудиторія

- Кавомани 22–55 років, що купують зернову/мелену каву додому
- Шукають чай (листовий, порційний, матча, пуер) як подарунок або для себе
- Покупці кави на розваг (250 г / 500 г / 1000 г)
- Жителі всієї України, що замовляють через НП

## 3. Сторінки та структура сайту

### 3.1 Головна (`/`)
- **Hero-секція:** великий заголовок + підзаголовок + CTA-кнопка "Обрати та замовити"
- **Блок "Про нас"** (коротко: хто ми, чим особлива наша кава)
- **Каталог-прев'ю** (8–12 популярних позицій з кнопкою "У кошик")
- **Переваги** (доставка НП, свіжеобсмажена кава, зручна оплата, гарантія якості)
- **FAQ** (5–7 відповідей)
- **Футер:** контакти, соцмережі, способи оплати, посилання на правові сторінки

### 3.2 Магазин (`/shop`)
- **Фільтри зліва/зверху:**
  - Категорія: Кава / Чай / Пуер / Порційний / Подарунковий / Посуд / Аксесуари
  - Підкатегорія: Вид кави, Вид чаю, Пуер, Посуд
- **Пошук** по назві
- **Сортування:** за замовчуванням / ціна ↑↓ / назва А–Я / новизна
- **Сітка карток товарів** (4 в ряд на десктопі, 2 на мобільному)

### 3.3 Картка товару (`/product/:slug`)
- Фото-галерея (3–5 фото)
- Назва, ціна, опис смакових нот
- **Опції фасування** (radio: 250г / 500г / 1000г для кави; 25г / 50г для матчі; 1шт для зв'язаного чаю)
- **Тип кави** (select: В зернах / Мелена)
- Кнопка "У кошик"
- Бейджі: "Топ продажів", "Знижка -15%", "Немає в наявності"
- Склад, країна походження, спосіб обсмаження

### 3.4 Кошик (`/cart`)
- Список товарів з можливістю змінити кількість / видалити
- Перерахунок суми
- Поле "Промокод" (опційно)
- Кнопка "Оформити замовлення"

### 3.5 Оформлення замовлення (`/checkout`)
**Форма з полями:**
| Поле | Тип | Обов'язкове | Примітка |
|------|-----|-------------|----------|
| ПІБ | text | ✅ | |
| Телефон | tel | ✅ | перевірка через маску |
| Email | email | ❌ | для чеку/листування |
| Місто | text | ✅ | |
| Відділення НП | text/number | ✅ | або "Адресна доставка" |
| Спосіб доставки | radio | ✅ | "У відділення НП" / "Адресна доставка" / "Самовивіз" (якщо є) |
| Спосіб оплати | radio | ✅ | "Передоплата на карту" / "Накладений платіж" / "LiqPay" |
| Коментар | textarea | ❌ | |

**Після сабміту:**
1. POST `/api/orders` (або Google Sheets endpoint)
2. Запис у Google Таблицю (окремий рядок на замовлення)
3. Email/телефон підтвердження клієнту + менеджеру
4. Редирект на сторінку "Дякуємо! Замовлення №… прийняте"

### 3.6 Інформаційні сторінки
- `/about` — Про нас
- `/delivery` — Умови доставки та оплати
- `/contacts` — Контакти, мапа, соцмережі
- `/privacy` — Політика конфіденційності
- `/offer` — Публічна оферта (закон про e-commerce)

### 3.7 Адмінка (опційно для MVP)
- Якщо MVP — без адмінки, керування через Google Таблицю вручну
- Якщо v2 — простий CMS (Astro/Sanity/Strapi) для редагування товарів

## 5. Функціональні вимоги

### 5.1 Кошик
- localStorage-персист (не губиться після перезавантаження)
- Бейдж з кількістю товарів у хедері
- Синхронізація кількості при зміні фасування

### 5.2 Інтеграція з Google Sheets
- Створити Google Таблицю з аркушами:
  - `Orders` — замовлення (дата, ПІБ, телефон, місто, склад НП, товари, сума, статус, спосіб оплати)
  - `Products` — каталог (опційно — щоб тягнути дані звідти, якщо немає CMS)
- Через **Google Apps Script Web App** (POST endpoint) або **Service Account + Google Sheets API**
- Перевага: Apps Script — простіше, не потребує бекенду для самої точки прийому

### 5.3 Інтеграція з Новою поштою
- v1: клієнт сам вводить місто + номер відділення
- v2 (опційно): API НП для підказки міста/відділення, автопідрахунок вартості

### 5.4 Оплата
- v1: реквізити картки в email/повідомленні менеджера, ручна перевірка
- v2 (опційно): LiqPay / Fondy checkout через їхній віджет

### 5.5 SEO та продуктивність
- SSR/SSG (Next.js / Astro / Nuxt)
- Meta-теги, OpenGraph, JSON-LD (`Product`, `BreadcrumbList`)
- sitemap.xml, robots.txt
- Lighthouse Performance ≥ 90, Accessibility ≥ 90

## 7. Технічний стек ✅ узгоджено

- **Front + Back:** Next.js 14 (App Router) + TypeScript
- **Стилі:** Tailwind CSS
- **Кошик:** Zustand + localStorage
- **Дані товарів:** JSON-файл (`data/products.json`) → легко додавати позиції
- **Замовлення:** POST `/api/orders` → Google Apps Script Web App → Google Sheets
- **Сповіщення менеджеру:** Telegram Bot API
- **Хостинг:** Vercel (поки без домену — на `*.vercel.app`)

### Бренд-айдентика (тимчасова)
- Логотип: плейсхолдер — текст "smart bar" + значок, без градієнтного кільця (замовник надішле фінальний логотип пізніше)
- Текст логотипу: білий sans-serif
- Кольори палітри (класична кавова, темна):
  - `--bg`: `#1B1410` (темно-кавовий фон)
  - `--surface`: `#2A1F18` (картки)
  - `--accent`: `#C8956D` (теплий кавовий акцент — кнопки, бейджі, лінки)
  - `--accent-hover`: `#B07F58`
  - `--text`: `#F5EFE7` (основний текст)
  - `--text-muted`: `#A8978A` (другорядний текст)
  - `--border`: `#3D2E22`
- Шрифт: Inter (placeholder — замінимо на брендовий пізніше)

## 9. Критерії приймання MVP

1. Сайт деплоєний на публічному домені, HTTPS працює
2. Каталог містить усі товари з фото, цінами, описами

## 10. Узгоджені рішення (відповіді замовника)

### Бізнес / контент
1. **Домен:** поки без домену, використовуємо `*.vercel.app`. Додамо пізніше.
2. **Бренд-айдентика:** тимчасова версія зі скриншота (див. розділ 7). Фінальний логотип і шрифт надішле замовник пізніше.
3. **Контент:** робимо заглушки для прикладу — 2 категорії (Кава / Чай) з 3–4 товарами в кожній. Структура JSON дозволяє легко додавати нові позиції.
4. **Ціни:** фіксовані, в UAH.
5. **Оплата:** тільки накладений платіж при отриманні Новою поштою.
6. **Доставка:** Новою поштою по всій Україні, у відділення. Без самовивозу.
7. **Мінімальна сума замовлення:** не встановлюємо (можна додати пізніше).

### Інтеграції
8. **Google Таблиця:** створимо нову, замовник надасть ID або створить сам за інструкцією.
9. **Сповіщення менеджеру:** через Telegram-бот (вказати `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID` через env).
10. **Соцмережі:** додамо заглушки-плейсхолдери (Instagram, Telegram).

### Технічні
11. **Стек:** ✅ Next.js 14 (App Router).
12. **CMS/адмінка:** не потрібна — товари в JSON, редагування через git.
13. **Бюджет/дедлайн:** без жорстких обмежень, MVP пріоритет.

### Що залишилось на потім (не блокує MVP)
- Реальний логотип і фірмові кольори (замінити плейсхолдер)
- Реальні фото товарів
- Реальні тексти "Про нас", FAQ
- Реальні ціни й асортимент
- Доменне ім'я
- Google Таблиця (потрібен ID або створити разом)
- Telegram Bot Token / Chat ID
